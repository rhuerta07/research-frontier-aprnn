# Binary artifacts

Core table reproduction needs only the small JSON records in `results/`.

No checkpoint, dataset image, upstream code or runtime overlay is redistributed here. No accessible, versioned public binary archive has been verified. Internal checkpoint hashes appear in the saved summaries and prediction metadata for identity checking; a hash alone does not make an artifact available or establish redistribution rights.

Full checkpoint replay is unavailable from this repository alone. Adding it requires rights clearance, versioned public artifact access, byte-hash checks and separate replay instructions. Do not substitute a private Deepnote URL for public access or introduce new cloud storage infrastructure.
